# Property Finder Saudi Scraper

Actor لاستخراج إعلانات العقارات من Property Finder Saudi.

## الوظائف

- البحث حسب المدينة.
- البحث حسب الحي.
- البيع أو الإيجار.
- نوع العقار.
- تحديد عدد النتائج.
- البحث عن إعلانات اليوم فقط.
- استخراج السعر.
- استخراج المساحة.
- استخراج غرف النوم.
- استخراج دورات المياه.
- استخراج رقم الهاتف عند توفره.
- استخراج اسم الوسيط عند توفره.
- استخراج وصف العقار.
- استخراج تاريخ نشر الإعلان.
- استخدام Apify Residential Proxy.
- إرسال Webhook اختياري عند انتهاء العملية.
